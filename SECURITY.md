# Security

Report a vulnerability in private. Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting:

<https://github.com/OpenBazaar/openbazaar-rs/security/advisories/new>

That report goes to the maintainers and stays off the public issue tracker. Include what is affected (the client, the home node, escrow, a wallet, or a dependency), the commit or release you tested, what an attacker can do, and the steps to reproduce it.

We will reply on the private advisory. Please give us time to fix the issue before you publish it.

Ordinary bugs, questions, and feature requests still belong in public issues.
